# Hujaif Belim — Developer Portfolio

Award-level single-page developer portfolio for **Hujaif Belim**, Flutter Developer and IMCA student from Ahmedabad, India.

## Stack
- **Framework:** React 19 + Vite + TypeScript
- **Styling:** Tailwind CSS v4 + bespoke CSS variables (editorial dark theme)
- **Animations:** Motion (Framer Motion), GSAP with ScrollTrigger
- **Smooth Scroll:** Lenis
- **Command Palette:** `cmdk` (accessible via `Ctrl + K` / `Cmd + K`)
- **Particle Engine:** Custom HTML5 Canvas physics engine (zero heavy 3D library overhead)
- **Deployment:** Vercel SPA rewrite configured via `vercel.json`

## Visual System
- **Background:** Deep ink-navy `#0A0E1A`
- **Surfaces:** `#111827`
- **Text:** Bone white `#F2EFE8`
- **Muted text:** `#8B93A7`
- **Accent:** Ember orange `#FF5A1F`
- **Typography:** Instrument Serif (display), Inter (body), JetBrains Mono (labels/code)

## Running Locally

```bash
npm install
npm run dev
```

Build for production:
```bash
npm run build
npm run preview
```
